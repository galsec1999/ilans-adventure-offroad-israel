# מדריך המסלולים — גרסת מסמך 2.1.5

גרסת מוצר: **2.1.0**  
סטטוס: פורסם כ־PWA ציבורי ב־GitHub Pages.

המוצר כולל 339 כרטיסי טיול: 304 מן המאגר המקורי ו־35 כרטיסים שקודמו מנספח קישורי Off‑Road. בגרסת מסמך 2.1.5 נמשכו נתוני מקור עבור כל 295 מזהי ה־Track הייחודיים שמקושרים מן הספר: 290 אומתו מול ה־API הציבורי וחמישה אינם זמינים כעת. מאה מועמדי מחקר נשמרו ב־`data/research-candidates.json` ואינם נספרים כמסלולים.

## הפעלה מקומית

יש להגיש את התיקייה בשרת HTTP מקומי. ב־Chrome ניתן להתקין את ה־PWA. כתובת האתר אינה מתועדת במסמך זה.

## יכולות מרכזיות

- סינון ומיון אמיתיים לפי אזור, קושי, תוואי, שלמות, מקור וניווט.
- נתוני Off‑Road לכל הקלטה זמינה: מרחק, זמן, סוג פעילות וקושי מן המקור, כולל הצגה נפרדת כאשר לכרטיס יש כמה הקלטות.
- הזמנת WhatsApp עשירה עם מפת Off‑Road, כרזה ו־QR.
- ייצוא כל כרטיס לקובץ HTML עצמאי.
- מצב בהיר כברירת מחדל ומצב כהה חם לבחירה.
- AI במכשיר המשתמש בלבד, ללא שרת או מפתח.
