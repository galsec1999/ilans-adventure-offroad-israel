# מדריך המסלולים — גרסת מסמך 2.3.3

גרסת מוצר: **2.5.1**

ספר PWA בעברית וב־RTL עם 339 כרטיסי טיול, 100 מקורות מחקר נפרדים, סינון ומיון, Dark Mode, מונה כניסות, הזמנות WhatsApp, כרזה ו־QR, AI מקומי, הקראה וייצוא HTML מלא לטיול יחיד.

בראש האתר יש מתג בולט בין **מצב בהיר** ל־**מצב חשוך**. הבחירה נשמרת לאחר רענון; בבורר המתקדם נשמרה גם האפשרות **לפי המכשיר**.

## מהדורת אמינות 2.5

- כל 339 הכרטיסים קיבלו ביקורת התאמה בין הכרטיס למפה.
- 290 שכבות Off‑Road נפתחו בפועל ונבדקו על פני 551,740 נקודות.
- שם, תיאור, מרחק, זמן, קושי, פעילות, מפה ו־QR בהזמנה ובייצוא נלקחים מאותה הקלטה.
- בכרטיס עם כמה מפות חובה לבחור הקלטה אחת לפני פרסום.
- 272 כרטיסים כוללים שמות יישובים ואתרים שנמצאו במרחק מדוד מן התוואי; קרבה אינה מוצגת כביקור ודאי.
- חמש סתירות פנימיות ב־Off‑Road וחמישה מקורות לא זמינים מוצגים בגלוי ולא הושלמו בניחוש.

## הפעלה מקומית

יש להגיש את התיקייה באמצעות שרת HTTP. ה־manifest, ה־Service Worker, הסמלים וכל הקישורים משתמשים בנתיבים יחסיים ומתאימים גם לנתיב משנה של GitHub Pages.

## מדיניות מידע

המדריך אינו אישור שמסלול פתוח, חוקי, עביר, בטוח או מתאים לקבוצה. יש לבדוק תנאי שטח, סגירות, מזג אוויר, ביטחון, שערים ורמת הרוכבים סמוך ליציאה. AI נדרש לומר שאין מספיק נתונים במקום להמציא.
