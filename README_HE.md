# מדריך המסלולים — גרסת מסמך 2.1.7

גרסת מוצר: **2.3.0**
סטטוס: פורסם כ־PWA ציבורי ב־GitHub Pages.

המוצר כולל 339 כרטיסי טיול: 304 מן המאגר המקורי ו־35 כרטיסים שקודמו מנספח קישורי Off‑Road. נשמרה העשרת המקור עבור כל 295 מזהי ה־Track הייחודיים שמקושרים מן הספר: 290 אומתו מול ה־API הציבורי וחמישה אינם זמינים כעת. מאה מועמדי מחקר נשמרו ב־`data/research-candidates.json` ואינם נספרים כמסלולים.

## הפעלה מקומית

יש להגיש את התיקייה בשרת HTTP מקומי. ב־Chrome ניתן להתקין את ה־PWA. כתובת האתר אינה מתועדת במסמך זה.

## יכולות מרכזיות

- סינון ומיון אמיתיים לפי אזור, קושי, תוואי, שלמות, מקור וניווט.
- נתוני Off‑Road מוקשחים בתוך ה־HTML לכל הקלטה זמינה: כותרת המקור, מרחק, זמן, סוג פעילות וקושי; בכרטיס רב־Track כל הקלטה מוצגת בנפרד.
- נתוני מרחק וזמן קשיחים לארבעה מסלולי Google Maps Directions שנבדקו; קישור שאינו מפיק מסלול מסומן בגלוי ללא נתונים מומצאים.
- סיווג הקושי במסנן מושלם ממקור Off‑Road כאשר הסיווג המקומי חסר; בכרטיס רב־Track הוא שמרני ומסומן כנגזר מן הדירוג הגבוה ביותר.
- הזמנת WhatsApp עשירה עם מפת Off‑Road, כרזה ו־QR, ולצדה הזמנה קצרה כמו בגרסה 1.5.
- שמירה ושיתוף של תמונת האווירה מכל כרטיס שבו קיימת תמונה.
- ייצוא כל כרטיס לקובץ HTML עצמאי הכולל את כל שדות הכרטיס, התמונות, נתוני המקור וכל המפות המקושרות.
- מונה כניסות ציבורי ללא מפתח, עם ספירה אחת ליום בכל מכשיר ותצוגת גיבוי מקומית.
- מצב בהיר כברירת מחדל ומצב כהה חם לבחירה.
- AI במכשיר המשתמש בלבד, ללא שרת, ללא מפתח API וללא תשלום מצד המדריך.
