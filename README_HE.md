# מדריך המסלולים המקומי — גרסת מסמך 2.1.4

גרסת מוצר: **2.1.0**  
סטטוס: תצוגה מקומית לפני אישור פרסום.

המוצר כולל 339 כרטיסי טיול: 304 מן המאגר המקורי ו־35 כרטיסים שקודמו מנספח קישורי Off‑Road לאחר אימות מטא־דאטה. מאה מועמדי מחקר נשמרו ב־`data/research-candidates.json` ואינם נספרים כמסלולים.

## הפעלה מקומית

יש להגיש את התיקייה בשרת HTTP מקומי. ב־Chrome ניתן להתקין את ה־PWA. אין לפרסם או לדחוף תיקייה זו לענן לפני אישור מפורש של אילן.

## יכולות מרכזיות

- סינון ומיון אמיתיים לפי אזור, קושי, תוואי, שלמות, מקור וניווט.
- הזמנת WhatsApp עשירה עם מפת Off‑Road, כרזה ו־QR.
- ייצוא כל כרטיס לקובץ HTML עצמאי.
- מצב בהיר כברירת מחדל ומצב כהה חם לבחירה.
- AI במכשיר המשתמש בלבד, ללא שרת או מפתח.
