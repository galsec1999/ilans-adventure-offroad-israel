# מדריך המסלולים — גרסת מסמך 2.2.0

גרסת מוצר: **2.2.0**
סטטוס: תצוגה מקומית לבדיקה; טרם פורסמה. גרסה 2.1.0 היא הגרסה הציבורית האחרונה.

המוצר כולל 339 כרטיסי טיול: 304 מן המאגר המקורי ו־35 כרטיסים שקודמו מנספח קישורי Off‑Road. נתוני המקור נשמרו עבור כל 295 מזהי ה־Track הייחודיים שמקושרים מן הספר: 290 אומתו מול ה־API הציבורי וחמישה אינם זמינים כעת. מאה מועמדי מחקר נשמרו ב־`data/research-candidates.json` ואינם נספרים כמסלולים.

גרסה 2.2 מוסיפה יומן שטח מקומי מלא. ההערות, הביקורות והתמונות נשמרות ב־IndexedDB במכשיר המשתמש ואינן נשלחות לשרת. אפשר לייצא גיבוי JSON מלא, לשתף אותו מן הטלפון, לייבא אותו במכשיר אחר ולהפיק דוח HTML מרוכז.

## הפעלה מקומית

יש להגיש את התיקייה בשרת HTTP מקומי. ב־Chrome ניתן להתקין את ה־PWA. כתובת האתר אינה מתועדת במסמך זה.

## יכולות מרכזיות

- סינון ומיון אמיתיים לפי אזור, קושי, תוואי, שלמות, מקור וניווט.
- נתוני Off‑Road לכל הקלטה זמינה: מרחק, זמן, סוג פעילות וקושי מן המקור, כולל הצגה נפרדת כאשר לכרטיס יש כמה הקלטות.
- הזמנת WhatsApp עשירה עם מפת Off‑Road, כרזה ו־QR.
- ייצוא כל כרטיס לקובץ HTML עצמאי.
- הערות וביקורות מקומיות לכל מסלול, כולל תאריך, מקור הדיווח, דירוג, תנאי רכיבה, תמונות וקישורי סרטונים.
- הפרדה בין חוויה אישית, דיווח מרוכב אחר וביקורת מן האינטרנט עם קישור מקור.
- גיבוי וייבוא JSON מלאים, שיתוף מן הטלפון ודוח HTML מרוכז.
- ייצוא HTML של כרטיס כולל גם את ההערות והתמונות המקומיות שלו.
- מצב בהיר כברירת מחדל ומצב כהה חם לבחירה.
- AI במכשיר המשתמש בלבד, ללא שרת או מפתח.
